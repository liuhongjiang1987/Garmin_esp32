# 意图分析

要点已写入已 pin 的 `SKILL.md` 主循环。默认不必读本文件；仅当意图含糊需要对照细则时再读。

把用户原话收成：本轮主交付类型 +（如需）查询意图 +（如需）主题卡。不要把展示话术写进查询意图。

## 先判类型

1. **打招呼 / 唤醒**：问候即可，不查库、不读主题卡。  
2. **闲聊或未点名指标**：澄清要查什么，不查库。  
3. **纯数字**：场次、距离、配速、SWOLF、划次等 → 写短查询意图 → 口报。  
4. **要解释 / 建议 / 进步吗**：写查询意图 → 自主选一张主题卡 → 单点分析或选题。  
5. **综合 / 整体 / 全面 / 怎么样**：先查能支撑总印象的最少数字（如最近三场距离、配速、SWOLF）→ 本轮只给总印象 + 选题；**不要**一次读多张主题卡。  
6. **CSS / 训练区 / 游多快 / 本周怎么练**：走 `css.md`，并用 CSS 工具，不靠猜。  
7. **改档案**：用户说出池长、周次、目标等 → 先 `save_profile_fields` 再答。

## 查询意图怎么写

只写「查什么」，例如：

- 「最近一场的距离」  
- 「最近三场的距离、配速和 SWOLF」  
- 「最近一场各圈的配速和泳姿」

不要写 SQL，不要写「按时间从早到晚」「用表格」等展示要求。多方面数字可以一条意图多指标，或本会话内再调一次工具。

## 主题卡怎么选（自主，不要求用户点名）

看用户用词和数据缺口，本轮只选**一张**：

| 信号 | 选用 |
|------|------|
| 效率、SWOLF、划次、划水沉 | `efficiency.md` |
| 后半程、顶不住、越游越慢、漂移 | `endurance.md` |
| 不稳定、忽快忽慢、左右、动作散 | `stability.md` |
| 会不会练伤、量太大、恢复差 | `load.md` |
| 有没有进步、最近一段时间、对比几场 | `trend.md` |
| 综合但尚未选题 | 本轮可不读主题卡，或只读与最显眼数据最贴的一张 |

用户已经点名主题时，以点名为准。未点名时由你根据意图选一张，并在口语里自然落到该角度，最后用选择题把其他角度留给下一回合。
