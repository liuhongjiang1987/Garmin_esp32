# CSS（临界游速）与训练区

CSS 是用来给配速训练分区的强度锚点，不是医疗指标。它大致对应一个人能维持三十到四十分钟的最快配速。

## 怎么测

常见测法是一次 400 米和一次 200 米全力游（中间休息充分），用 (400 米用时 − 200 米用时) ÷ 2 得出 100 米配速。也可以用用户自报的能稳定维持的配速做参考，但要标明「自报」。不要编造 CSS 值，也不要冒充手表自动官方值。

## 训练区（默认秒差，可按体感微调）

- Z1 有氧恢复：比 CSS 慢 15~25 秒/100米，轻松放松。
- Z2 有氧技术：比 CSS 慢 8~15 秒/100米，稳定有氧，适合打磨动作。
- Z3 阈值：CSS 正负 2 秒/100米，接近临界强度。
- Z4 短距质量：比 CSS 快 3~8 秒/100米，短距高强度。
- Z5 冲刺：比 Z4 更快，全力短距离。

说训练区时不要只甩字母。要说到相对 CSS 差几秒，或具体配速。

## 本周处方

点名展开时最多给三条可执行组次，不能更多。每条写清距离、组数、配速区、间歇时间。超过三条或不附复测提醒，都算未达标。

示例：「这周可以试三个内容：一是 4×100 米 Z2 配速，间歇 20 秒；二是 6×50 米 Z4 配速，间歇 30 秒；三是连续 400 米 Z2 当放松。」

## 复测

默认四到八周复测一次。到期提醒，不到期不催。复测后必须同时更新锚点、区和组次——禁止只改一个数字。锚点进步或退步都要如实更新。

## 口述规则

不要把区表当成周期化课表引擎。仍遵守语音回合预算：无锚点时本轮只引导测试或自报；有锚点且用户要展开时，再「出区 + 最多三条 + 复测提醒」，不要一次把背景课全说完。

CSS 来自用户自报或自测，标明来源。不要说「手表自动测出」或「官方值」。

没有 CSS 锚点时，引导用户做一次测试或自报一个参考配速，不要凭空编区。

工具：先 `query_css_anchor`；保存或更新用 `save_css_anchor`（区和组次一起更新，禁止只改一个数字）。
