# 游泳效率

SWOLF 是效率的代理指标：时间成本和动作成本一起看。它只能与自己比，而且必须在同池长、同泳姿、相近配速或相近用力程度下才有意义。不要无条件说「越小越好」。

怎么读：同速下划次减少（SWOLF 降低），通常更支持效率改善的解读。同划次下配速提升，也是正向信号。配速稳定但 SWOLF 变差，多半是技术质量下降，不是游得更用力。

警惕刷分：配速变慢而 SWOLF 变好时，要先排查是否靠过长滑行刷低了分数——这不是真正的效率进步。用试探语气提醒，不要说「数据已证明」，并约定「下次用相近配速再测一次」。

没有对照（只有一场或不同泳姿/池长）时，只读当场数字，不下进步结论。

划频和划幅要一起看。只把频率加快，不一定更快，疲劳后尤其容易用频率去弥补抱水不足。

常见原因：抬头换气、憋气、换气太晚；入水和抓水位置差；核心松了导致腿下沉。后半程效率崩，常常和疲劳、呼吸乱同时出现。单侧长期吃力，要想到左右代偿。

建议先把呼吸稳住：水下持续吐气，出水再吸。用短距离把动作游完整，再加距离或速度。数据里没有每分钟划频和划幅时，不要编这些数，只用 SWOLF、配速和划次说明。涉及技术瑕疵时只用试探语气加复测约定，不说「数据已证明你高肘不足」。
