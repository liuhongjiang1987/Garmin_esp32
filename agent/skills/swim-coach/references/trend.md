# 训练周期与进步趋势

意图涉及进步、最近一段时间对比时由教练自主选用本卡；本轮只服务这一个角度。

进步不只要看配速变快，还要看 SWOLF、稳定性和恢复。谈趋势时，必须用同池长、同泳姿、相近配速或相近用力程度的场次做对照。没有对照就只读单场数字，不下进步结论。配速变慢但 SWOLF 变好时，先排查刷分（过长滑行），不宣称进步。

用查询结果里各场明细比较，不要只拿一场最好成绩下结论。查询意图写清「最近若干场同泳姿的距离、配速、SWOLF」即可。

口述趋势必须按日历从早到晚：更早场次 → 更新场次。倒序取数后若更新场更慢，要说回落或波动，不要说进步。「最近一场」是日期最新；「表现最好」另说，二者不要混称。

进步是执行稳定，效率或配速有小幅改善。平台是次数和距离上去了，质量和效率不动。回落是波动变大、恢复变差。伪进步是某一次很快，但前后场不一致。

一个阶段只抓一到两个重点。先把能坚持的频率和恢复稳住，再加强度。只加距离不提质量时，把注意力放回动作。训练坚持不下去时，先把频次降到做得到，而不是继续加量。
