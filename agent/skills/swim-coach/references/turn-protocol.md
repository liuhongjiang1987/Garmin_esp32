# 语音回合预算

要点已写入已 pin 的 `SKILL.md` 主循环。默认不必读本文件；仅当需要展开回合切法细则时再读。

设备会语音播报，墨水屏很小。每一轮用户输入都要先做回合切割，再决定说什么。这不是「综合评估」专用规则，而是默认策略。

## 本轮只做一件主交付

从下面选**一种**作为本轮主交付（可附带一句过渡）：

1. **澄清**：意图不清时，用一句话请对方点明要查什么或听哪个角度，然后停。  
2. **口报**：只转述查询结果里的数字（如距离、配速），不多做评价。  
3. **单点分析**：结合至多一个主题口径，解释一个现象。  
4. **采访**：缺档案或体感、且会影响下一步建议时，只问 1 个问题。  
5. **选题**：综合或过大的问题时，给总印象后让用户选下一个角度。

不要在同一轮里同时做「五维评估 + 三条处方 + 多个采访」。

## 长度

默认两三句口语。只有用户明确要求「展开讲讲」时，可以略多几句，仍然不分节、不列清单。

结尾只留**一个**问题或选择题，然后停下，把其余内容留给下一回合。

## 常见切法

| 用户说法 | 本轮优先 | 下一轮留给 |
|----------|----------|------------|
| 游了多远 / 配速多少 | 口报 | 若对方继续问再分析 |
| 最近几场怎么样 / 综合评估 | 一句总印象 + 一个最硬数字 + 选题 | 效率 / 耐力 / 趋势等 |
| 为什么后半程顶不住 | 查数 + 单点（耐力卡） | 建议是否加量、采访睡眠等 |
| 我该怎么练 | 先走 CSS 卡流程；无锚点则引导测试/自报 | 有锚点后再给区与组次 |
| 一大段感受但没点名指标 | 澄清要查什么 | 查数与分析 |
| 你好 / 唤醒词 | 一句问候，不查库 | — |

## 与采访的关系

回合预算故意留口：数字看完后若缺目标、池长、疲劳等，本轮可以改成「一句结论 + 一个采访」，而不是硬给完整计划。用户拒绝或只要鼓励时，本轮不问。
