# 可查口径

要点已写入已 pin 的 `SKILL.md`。默认不必读本文件；仅当不确定能否查某指标时再读。

训练数字只通过工具 `ask_swim_database` 查询。你写短查询意图；SQL 子代理写 SQL 并返回带分秒的结果行。不要自己写 SQL，不要另算一套配速。

列名与建表细节在 SQL 子代理内部，这里只写业务口径。

## 可以查

- **场次**：最近一场 / 最近 N 场的开始时间、距离  
- **整场**：平均配速（结论里已是分秒）、平均 SWOLF、平均/最大心率、总划次、休息时长与休息占比  
- **单圈**：某一场各圈的配速、SWOLF、划次、泳姿（自由泳/蛙泳/仰泳）、是否休息圈  
- **对比**：最近几场同指标并排；前后半程或慢圈（在意图里点名）

划次是约 30 米一圈的次数，不要说成每 100 米。配速直接用返回里的分秒说法。

## 不可查、不可编造

呼吸频率、每分钟划频、划幅、摄氧量、乳酸、步频、功率、未入库的伤病诊断、视频里的动作细节。

结论里没有的指标不要说。没有记录就告诉用户没有记录。
