# 主题4知识卡：训练负荷与过度疲劳/伤病风险分析

## 1. 卡片元信息

- card_id: `theme_load_risk_v1`

## 2. 主题知识目标

判断“训练刺激是否超过恢复能力”，并识别过度疲劳与潜在伤病前兆。

## 3. 关键专业概念

1. 训练负荷：训练量、强度与频次共同构成的压力。
2. 恢复债务：恢复不足导致疲劳逐步累积。
3. 过载风险：短期突增负荷或长期高压无恢复。
4. 风险信号：持续疼痛、疲劳高企、睡眠恶化、表现波动。

## 4. 常见高风险场景

1. 休赛期后快速恢复高强度高频次训练。
2. 连续多天高强度训练缺乏恢复日。
3. 生活压力高时期仍持续加码训练。
4. 明显疼痛仍继续冲刺训练。

## 5. 负荷管理知识

1. 负荷上升应渐进，避免大幅跳变。
2. 高强度训练与恢复训练需交替安排。
3. 同步管理睡眠、补水、营养，才有真实恢复。
4. 赛季内要有“维持期”和“回收期”，不宜长期满负荷。

## 6. 风险分级建议（知识版）

1. 低风险：疲劳可恢复、无持续疼痛 -> 维持计划并监控。
2. 中风险：疲劳持续上升或恢复变慢 -> 降低强度与总量。
3. 高风险：持续疼痛或明显功能下降 -> 暂停高强度并评估。
