## 2. 主题知识目标

从训练周期视角判断“进步、平台或回落”，并给出下一周期的训练方向原则。

## 3. 关键专业概念

1. 周期训练：赛季前、赛季中、赛季后目标不同。
2. 进步不只看速度，也看效率、稳定性与恢复质量。
3. 平台期常见于“量上去了，质量没跟上”。
4. 可持续进步依赖渐进负荷和阶段性恢复。

## 4. 周期判读知识

1. 进步期：执行稳定，效率或速度持续微改善。
2. 平台期：训练频次和总量在升，质量指标停滞。
3. 回落期：波动放大、恢复变差、疲劳信号增加。
4. 伪进步：单次最好成绩提升但整体一致性下降。

## 5. 周期规划原则

1. 每周期主目标不宜过多，通常 1-2 个。
2. 先稳执行与恢复，再追更高强度。
3. 赛季中更注重比赛准备与恢复，而非盲目堆量。
4. 赛季后应安排恢复与反思，防止长期透支。

## 6. 常见问题与修正方向

1. 只加量不提质：增加技术质量训练占比。
2. 过度追求单次表现：改为跟踪周期均值和波动。
3. 训练不可持续：回调频次并重建可执行节奏。
