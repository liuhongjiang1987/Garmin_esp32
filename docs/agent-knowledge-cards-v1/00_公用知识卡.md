## 2. 适用目标（专业知识范围）

1. 提供所有主题共用的游泳教学与训练科学基础。
2. 提供安全、恢复、沟通、心理准备等跨主题知识。
3. 不包含路由、字段、工具、状态写入等框架设计内容。

## 3. 通用执教原则（知识层）

1. 安全第一：游泳先是生存技能，再是竞技技能。
2. 技术优先：动作质量优先于盲目加量。
3. 训练闭环：热身、主训练、放松恢复缺一不可。
4. 长期主义：稳定执行比单次极限训练更重要。
5. 个体化：同一训练量对不同运动员的负担不同。

## 4. 通用安全知识

1. 训练前检查：水质、深浅标识、防滑、照明、应急通道。
2. 训练中保障：足够监护和救生覆盖。
3. 入水出水：按能力采用最安全方式（梯子/辅助设备）。
4. 深水前提：具备基本漂浮、踩水和方向控制能力。

## 5. 呼吸与姿态通用原理

1. 水中呼吸核心是“水下持续吐气，出水快速吸气”。
2. 头位会改变腿位和阻力，影响效率与稳定性。
3. 流线型是最基础的减阻技术。
4. 呼吸节奏紊乱会放大技术错误与心理焦虑。

## 6. 热身与放松知识

1. 热身建议包含有氧激活、动态活动、专项动作。
2. 放松阶段帮助心率、呼吸和肌肉张力回落。
3. 热身不足和放松缺失会提升损伤风险。

## 7. 常见损伤与预防知识

1. 常见负担部位：肩、下背、膝、肘、踝。
2. 预防主线：技术质量、负荷节奏、恢复管理。
3. 持续疼痛应降负荷并做专业评估。

## 8. 恢复、营养与补水知识

1. 游泳同样会脱水，训练前中后都需补水。
2. 训练前进食需留足消化时间，降低抽筋与不适风险。
3. 恢复三要素：睡眠、补水营养、主动放松。

## 9. 教学反馈知识

1. 纠错遵循“先肯定、再聚焦一个改进点、再鼓励”。
2. 指令遵循 3C：清晰、简洁、一致。
3. 目标设定应可衡量、分层级、可执行。
