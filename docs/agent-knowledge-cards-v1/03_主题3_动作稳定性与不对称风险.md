## 2. 主题知识目标

识别动作一致性下降与潜在不对称代偿风险，给出“先稳动作、后提强度”的技术方向。

## 3. 关键专业概念

1. 动作稳定性：同样任务下动作质量的一致程度。
2. 不对称代偿：左右链路负荷或动作模式长期偏移。
3. 技术崩塌点：疲劳后最先失稳的技术环节（呼吸/入水/抱水/踢水）。
4. 质量优先原则：当动作明显失稳时，应先降强度修正技术。

## 4. 常见表现

1. 后半程动作突然变散，配速和效率波动增大。
2. 单侧肩背或髋部反复紧张、疲劳更快。
3. 长期单侧换气导致左右节奏不均。
4. 不同泳姿表现差异过大，提示专项动作链不平衡。

## 5. 原因知识

1. 核心稳定不足，难以维持流线型。
2. 抓水路径不稳定，推进方向偏移。
3. 呼吸时抬头或转头过大，破坏身体线条。
4. 疲劳管理不足，使动作控制在后程失守。

## 6. 训练干预知识

1. 双侧换气过渡练习，减少偏侧依赖。
2. 单臂划水与节奏控制分解练习，重建路径感。
3. 短组高质量训练，避免“带病硬撑长组”。
4. 必要时用视频或线下观察做动作校核。
