# 主题1知识卡：游泳效率分析（SWOLF + 划频/划幅）

## 2. 主题知识目标

解释“效率变化为什么发生”，重点覆盖配速、划次、呼吸节奏和身体姿态之间的关系。

## 3. 关键专业概念

1. SWOLF 是效率代理值，通常反映“时间成本 + 动作成本”。
2. 划频与划幅是动态平衡：单纯提频不一定提速。
3. 配速稳定但 SWOLF 变差，常见于技术质量下降。
4. 高效游进通常建立在流线型姿态、有效抱水和稳定呼吸上。

## 4. 常见低效机制

1. 呼吸失序：抬头换气、憋气、换气时机延后。
2. 抱水不足：入水和抓水位置不佳，推进效率低。
3. 频率代偿：疲劳后靠加快手脚频率维持速度。
4. 姿态失稳：核心控制下降，腿位下沉导致阻力增大。

## 5. 训练干预知识

1. 呼吸控制：先建立“水下持续吐气 + 出水快速吸气”。
2. 技术优先：短距离技术组优先于盲目拉长距离。
3. 节奏校准：用可持续节奏找回动作完整性，再逐步提速。
4. 分解练习：单臂划水、前交叉、划水滑行、握拳游等可用于强化抓水与平衡。

## 6. 观察与判读要点

1. 同速下 SWOLF 上升，常提示动作效率下降。
2. 后半程效率崩塌，常与疲劳和呼吸节律失控同时出现。
3. 单侧长期吃力，需警惕不对称代偿链路。
