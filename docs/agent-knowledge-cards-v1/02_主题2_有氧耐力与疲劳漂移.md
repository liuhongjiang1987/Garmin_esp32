## 2. 主题知识目标

解释“后半程为什么掉速/效率下滑”，区分正常疲劳与异常疲劳漂移。

## 3. 关键专业概念

1. 疲劳漂移：训练后段在相同意图下出现效率与速度同步恶化。
2. 恢复能力：负荷后心率、呼吸与动作质量回落的能力。
3. 隐性疲劳：速度看似稳定但主观疲劳和动作控制变差。
4. 负荷-恢复平衡：表现提升来自刺激与恢复的交替，而非持续加压。

## 4. 典型漂移信号

1. 后半程配速变慢且 SWOLF 变差。
2. 组间休息后恢复感变差、再次入组质量下降。
3. 换气节奏更乱、动作完整性下降。
4. 主观感觉从“可控累”转为“顶不住”。

## 5. 常见原因知识

1. 配速策略过激，前段消耗过大。
2. 睡眠、补水、营养不足导致恢复债务累积。
3. 近期生活压力叠加，降低可恢复能力。
4. 热身不足或组间恢复设计不合理。

## 6. 训练干预知识

1. 分段化训练：把长段拆成可控短段，优先保质量。
2. 强弱交替：高强度日后安排恢复性训练。
3. 恢复优先：补水、睡眠、低强度放松游同步执行。
4. 赛季内控制负荷波动，避免短期突增。

## 7. 耐力专项补充（整合外部资料）

1. 先慢后快：耐力训练初期先建立可持续配速，再逐步提强度。
2. 呼吸节奏优先：保持稳定换气比盲目追速度更能延缓后程崩塌。
3. 间歇训练用于耐力提升：通过短休息和重复组提高长时稳定输出能力。
4. 稳定长游不可缺：每周应有连续稳定游，用于建立节奏与心理耐受。
5. 陆上核心训练协同：核心稳定可降低水中额外阻力，提高动作经济性。
6. 交叉有氧有价值：步行、骑行、慢跑等可提升心肺并减轻泳池重复负荷。
7. 补给与恢复是耐力的一部分：缺水、睡眠不足会显著放大疲劳漂移。
8. 进步应被追踪：通过周期日志观察“同配速疲劳感下降”这一关键改进信号。
