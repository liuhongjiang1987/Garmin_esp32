# 项目文档：Garmin 私有运动数据语音分析终端

> 
> 文档类型：产品&系统规划文档
> 项目名称：Garmin私有运动数据语音分析终端
> 版本：V1.0
> 日期：2026-10-16
> 说明：本文档记录**需求、架构、应用流程、数据拓扑、网络、部署约束**；Agent业务逻辑独立开发，不在本文详细展开。

## 1. 需求概述

### 1.1 项目目标

搭建一套私有化运动数据语音查询终端。使用Waveshare ESP32-S3-ePaper-1.54墨水屏作为语音交互硬件；佳明手表运动数据统一存储在家庭NAS本地SQLite，原始运动数据不上传第三方大模型平台；通过语音唤醒，自然语言提问，由NAS上部署的Agent完成运动数据查询与分析，终端展示文本并语音播报结果。

### 1.2 核心需求

1. **数据采集**：自动同步Garmin Connect活动数据至本地NAS，存入SQLite数据库；
2. **本地存储**：所有原始运动指标（活动记录、心率、SWOLF、配速、训练负荷等）持久化保存在NAS本地，原始数据不对外流出；
3. **语音交互终端**：ESP32墨水屏终端支持离线语音唤醒、拾音；复用小智AI ASR/TTS云端能力；
4. **内网Agent调用**：ESP32获取ASR识别文本后，访问NAS内网HTTP接口，交由LangChain Agent处理；
5. **LLM调用**：Agent调用硅基流动（SiliconFlow）API，仅上传用户提问+精简汇总指标，原始运动数据不提交硅基；
6. **终端输出**：Agent返回的分析文本在墨水屏展示，并通过TTS合成语音播放；
7. **安全约束**：数据库仅允许只读查询，禁止增删改操作；内网接口增加访问鉴权；不将NAS服务暴露到公网。

### 1.3 非功能需求

1. 网络：ESP32接入家庭2.4G WiFi，同时可访问外网与局域网NAS；
2. 可用性：支持待机离线唤醒，WiFi断连、服务异常时有友好提示；
3. 性能：问答响应控制在数秒级别；墨水屏输出适配短文本；
4. 隐私：原始运动数据保留本地；音频上传小智云端，仅用于ASR/TTS。

### 1.4 排除范围（不在本文档实现，独立开发）

- LangChain Agent核心逻辑、提示词、工具链、LLM业务编排单独开发，不属于本文档范围。已落地的游泳教练第一版见 `docs/游泳教练Agent设计文档.md`：主教练负责口语，训练数字由只读 SQL 子代理查询；
- Agent的记忆、多轮对话业务规则独立设计；
- 不包含完整产品外壳、PCB硬件改版，仅使用现成开发板。

## 2. 系统架构

分层架构：**ESP32终端层 ↔ NAS内网服务层 ↔ 第三方API层**

```
flowchart LR
    A[Waveshare ESP32-S3-ePaper-1.54<br/>修改版小智固件] -->|外网：音频流| B[小智云端 ASR]
    B -->|返回识别文本| A
    A -->|内网HTTP POST（用户提问）| C[NAS：FastAPI 接口服务]
    C --> D[LangChain Agent（独立开发）]
    D --> E[(SQLite: GarminDB运动数据库)]
    D -->|公网文本请求| F[硅基流动 SiliconFlow LLM API]
    D --> C
    C -->|返回回答文本| A
    A -->|外网：回答文本| G[小智云端 TTS]
    G -->|音频流| A
```

### 2.1 ESP32终端层

硬件：Waveshare ESP32-S3-ePaper-1.54，板载ESP32-S3、ES8311音频Codec、麦克风、1.54寸墨水屏；外接4Ω腔体喇叭。
固件：基于小智AI开源固件二次修改。

- 保留模块：ESP-SR离线唤醒、VAD人声检测、音频采集压缩、墨水屏驱动、WiFi、TTS音频播放；
- 修改模块：ASR识别完成回调逻辑，不再转发至小智官方Agent，改为内网调用NAS FastAPI接口。

### 2.2 NAS内网服务层

部署在家庭NAS（Docker容器化）

1. GarminDB：定时拉取Garmin Connect活动数据，增量写入SQLite；
2. FastAPI Web服务：提供内网HTTP接口，接收ESP32上传的用户提问，转发至LangChain Agent，返回Agent生成的回答文本；
3. SQLite数据库：存储全部佳明原始运动数据；> 
> 注：LangChain Agent代码独立项目，对接FastAPI与SQLite。

### 2.3 第三方API层

1. 小智AI云端：ASR语音转文字、TTS文字转语音；传输内容：用户语音音频、最终回答文本；**不接收任何佳明运动数据**。
2. 硅基流动API：LLM推理；传输内容：用户问题 + 精简汇总指标；**原始数据库记录不上传**。

## 3. 应用业务流程

1. 用户使用佳明手表完成一次运动活动，活动数据自动同步至Garmin Connect；
2. NAS容器GarminDB按预设周期轮询Garmin Connect，增量拉取新活动，解析指标存入本地SQLite；
3. 用户在ESP32墨水屏终端说出唤醒词（你好小智），设备本地ESP-SR唤醒，开始拾音；
4. ESP32将采集音频上传小智云端ASR，得到识别后的文本（用户提问）；
5. ESP32将识别文本，通过内网WiFi发送POST请求至NAS上FastAPI接口；
6. FastAPI接收请求，调用LangChain Agent；
7. Agent执行：生成SQL查询语句 → 本地只读查询SQLite → 获取运动指标 → 调用硅基流动LLM生成自然语言分析结论；
8. Agent将结论文本返回FastAPI；
9. FastAPI将文本回传给ESP32终端；
10. ESP32将回答文本送入小智TTS接口获取音频流，外接喇叭播放语音；同时墨水屏刷新展示分析文本；
11. 对话结束，设备回到待机监听唤醒词状态。

## 4. 数据拓扑与数据流向

### 4.1 数据存储位置

- SQLite数据库文件：保存在NAS本地硬盘；存储完整活动记录、心率曲线、SWOLF、配速、训练负荷、恢复分数等原始运动数据；
- API密钥（硅基流动、Garmin账号、内网接口鉴权Key）：存放NAS环境变量，不写入ESP32固件；
- ESP32设备：不持久存储运动数据，仅临时缓存对话文本。

### 4.2 数据流向与边界

1. GarminDB ↔ Garmin Connect：仅同步运动活动数据；
2. GarminDB → SQLite：本地持久化写入；
3. Agent → SQLite：**仅SELECT只读查询，禁止DML/DDL**；
4. Agent → 硅基流动API：仅发送用户提问+精简统计指标；原始记录、GPS轨迹、完整心率曲线可配置过滤，不提交第三方；
5. ESP32 ↔ 小智云端：仅音频流（ASR）、回答文本（TTS）；**无任何佳明运动数据**；
6. ESP32 ↔ NAS：仅用户提问文本、回答结论文本；内网传输，不出公网。

## 5. 网络设计

### 5.1 网络拓扑

- ESP32、NAS、路由器处于**同一局域网**；
- ESP32连接2.4G WiFi；
- 外网访问：ESP32访问小智API；NAS访问Garmin Connect API、硅基流动API；
- 内网访问：ESP32通过NAS静态内网IP访问FastAPI服务。

### 5.2 网络前置配置

1. 路由器关闭AP隔离（客户端隔离），保证局域网WiFi设备互通；
2. NAS配置**静态内网IP**，防止DHCP重启后IP变更；
3. NAS防火墙放行FastAPI监听端口；Docker容器开放对应端口；
4. 安全策略：**NAS FastAPI接口仅内网可访问，不暴露公网**。

### 5.3 带宽评估

所有流量为低带宽文本/OPUS压缩音频，家用2.4G WiFi满足需求：

- ASR音频流：OPUS压缩，KB/s级别；
- ESP32 ↔ NAS：纯文本HTTP请求；
- NAS ↔ 硅基流动：纯文本API调用。

### 5.4 异常网络处理

- WiFi断连：ESP32检测网络状态，墨水屏提示网络异常；
- NAS服务不可达：ESP32捕获HTTP超时，返回友好提示；
- 第三方API（小智/硅基）超时：终端提示服务暂时不可用。

## 6. 部署要求

### 6.1 NAS硬件&环境要求

1. 硬件：支持Docker运行的NAS（群晖、威联通等）；低功耗CPU足够，不需要GPU；
2. 运行环境：Docker + Docker Compose；
3. 持久化存储：分配独立存储目录挂载给GarminDB，持久保存SQLite数据库文件；
4. 网络：可访问外网，用于同步Garmin Connect、调用硅基流动API；
5. 权限：容器只读约束SQLite，限制数据库仅SELECT查询。

### 6.2 ESP32终端部署要求

1. 硬件：Waveshare ESP32-S3-ePaper-1.54，外接4Ω腔体喇叭；配套USB供电或锂电池供电；
2. 固件：基于小智AI开源ESP-IDF源码，修改会话回调代码，编译烧录；
3. 配置：写入家庭WiFi账号密码，配置NAS内网IP、FastAPI接口地址、内网接口鉴权Token；
4. 屏幕：提示词约束输出简短文本，适配墨水屏低刷新特性。

### 6.3 容器服务部署清单（NAS）

1. GarminDB容器：定时同步Garmin Connect，输出SQLite数据库；
2. FastAPI容器：内网接口服务，接收ESP32请求，调用LangChain Agent；> 
> LangChain Agent为独立Python应用，可同容器或独立容器部署。

## 7. 风险与约束

| 风险 | 描述 | 应对约束 |
| --- | --- | --- |
| Garmin Connect会话失效 | GarminDB依赖登录session，会定期过期，停止同步数据 | 增加会话状态监控，自动刷新会话，增加日志告警 |
| SQL注入风险 | LLM生成危险SQL语句修改数据库 | 数据库只读；增加SQL语法前置校验，拦截DROP/ALTER/DELETE/UPDATE等关键字 |
| 固件上游变更 | 小智官方更新固件代码，导致二次修改版本合并困难 | Fork固定版本源码，不自动同步上游更新 |
| 内网IP变动 | NAS DHCP动态IP，ESP32无法访问服务 | NAS设置静态内网IP |
| API成本 | 每次问答两次LLM调用（SQL生成、结论生成） | 增加查询结果缓存，减少重复调用；限制连续高频提问 |
| 墨水屏交互限制 | 刷新速度慢，不适合长文本 | 业务层控制回答输出长度，精简结论 |
